# Cosmic Horror

Card game strategico a controllo territoriale, con tema orrore cosmico. Digital-first, sviluppato sul percorso web.

Il punto di ingresso della documentazione è il **[Master Index](docs/00_MASTER_INDEX.md)**: istruzioni, gerarchia delle fonti, stati dei documenti e indice.

Documenti principali:

- [Master Index](docs/00_MASTER_INDEX.md)
- [Protocollo di lavoro Cowork e Claude Code](docs/CT_COWORK_CODE_PROTOCOL_V0.4.md)
- [Vision e pilastri](docs/00-project-overview/01-vision-concept/)
- [Decision Log](docs/00-project-overview/03-decisions-changelog/)

Struttura del repository:

- `docs/`: documentazione (stato deciso del progetto);
- `game/`: codice (in `game/prove/` le prove tecniche, conservate come storia);
- `reference/`: materiale di sola consultazione.

Il prefisso `CT_` dei documenti è una sigla storica (il progetto si chiamava «Cosmic Territory»).
